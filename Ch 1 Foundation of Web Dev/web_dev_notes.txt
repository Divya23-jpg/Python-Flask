11.URL[Uniform Resource Locator]
    A URL is the unique web address of a page, file, or resource online.
    It tells the browser where to find the resource and how to access it.
    
    Exam:https://www.example.com:443/path/page.html?search=python#section2

    part                        MEANING
   https://	Protocol     (how to access: HTTP/HTTPS)
   www.example.com	     Domain name (server address)
   :443	Port number      (optional, default for HTTPS)
   /path/page.html	     File path (location of resource)
   ?search=python	     Query string (parameters sent to server)
   #section2	         Fragment (specific part of the page)

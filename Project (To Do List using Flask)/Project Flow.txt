We are building "A Full Stack To- Do List Web application"

Core Features:
1.User login: User can login with username / password
2.User Logout: They can safely log out
3.Create task: Add new To-do list
4.View tasks: See all your tasks
5.Update tasks: Edit task name or mark it as done




Technologies & Tools We will Use:

1. Flask: Our main Python web Framework
2. SQLite: Simple database stored in a file
3. SQLAlchemy : ORM to interect with the database using Python
4. Flask-WTF: Form Validation (like login, add task)
5. Jinja2: To render Dynamic HTML Templates
6. Flask-Login: Manage Logged in session (Optional its assignmnet)
